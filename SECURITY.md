# Security policy

## Supported versions

Security fixes are provided for the latest published release line.

| Version | Supported |
|---|---|
| 0.9.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Please report suspected vulnerabilities privately to `info@hcc2d.com`.
Include the affected version, execution environment, reproduction steps,
impact, and any suggested mitigation. Do not include real secrets or sensitive
third-party data in a report.

Please do not open a public issue for an unpatched vulnerability. A report will
be acknowledged as soon as practical, evaluated, and coordinated before public
disclosure. Good-faith reports and reasonable time for remediation are
appreciated.

The package intentionally contains no network requests, telemetry, install
hooks, native npm add-ons, or dynamic code downloads. Security reports about
the npm registry, Node.js, GitHub, or unrelated HCC2D applications should be
sent to the respective maintainers instead.
